## 🎨 Overview

**Jixu Design** is a creative design playground and component library built with **React + Vite**. It serves as a sandbox for experimenting with interactive UI patterns, micro-animations, and design system primitives — a space to prototype and refine components before using them in production projects.

---

## ✨ Features

- 🧩 **Component Playground** — Experiment with reusable UI patterns
- 🎭 **Animation Lab** — Test micro-interactions and transitions
- 🎨 **Design Tokens** — Color palettes, typography, and spacing scales
- ⚡ **Hot Module Replacement** — Instant feedback via Vite's HMR
- 🧪 **Rapid Prototyping** — Quickly iterate on design ideas
- 📐 **Responsive Testing** — Components built mobile-first

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Jixu-Dev/Jixu-design.git
cd Jixu-design

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
